	====================================================
	REAL-WORLD PROBLEM
	====================================================

	This application must address a genuine real-world problem:

	Beginner programmers often struggle to understand how code executes internally. They may memorize syntax, but they fail to understand control flow, loop behavior, condition branching, variable updates, and why a particular output is produced. This leads to poor programming fundamentals, confusion during interviews, and frustration during learning.

	LogicLens solves this by turning beginner Java programs into an interactive execution experience with tracing, explanation, variable tracking, output simulation, and flow visualization.

	Target users:
	- beginner programming students
	- coding bootcamp learners
	- first-year CS students
	- self-learners preparing for interviews
