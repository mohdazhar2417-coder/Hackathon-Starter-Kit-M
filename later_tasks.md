# LogicLens Future Roadmap 🗺️

This document tracks the long-term vision for LogicLens, capturing advanced features and "Power User" utilities planned for future phases.

## 🚀 Upcoming Phases

### Phase 3: Time Travel & Reversible Debugging
- [ ] **Step Backward**: Implement "Undo" logic in the simulation engine to rewind execution steps.
- [ ] **State Snapshots**: Efficiently store diffs between steps to allow instantaneous backwards jumping.
- [ ] **History Timeline**: A draggable slider to scrub through the entire execution history.

### Phase 4: Power User Utilities
- [ ] **Flowchart Mini-map**: A small overview window for navigating large, complex algorithm flowcharts.
- [ ] **Export Suite**: 
    - [ ] Export Flowchart as **SVG/PNG** for reports.
    - [ ] Export Execution Log as **JSON/PDF**.
- [ ] **Focus Mode**: A "Zen" interface that hides the sidebar and metadata, leaving only the Flowchart and Code View.
- [ ] **Speed Control**: A fine-grained slider for Auto-Play speed (from 0.5x to 4x).

### Phase 5: AI Insights & Smart Tutoring
- [ ] **AI-Generated Step Explanations**: Use LLMs to provide context-aware descriptions of complex logic steps.
- [ ] **Smart Error Detection**: AI that explains *why* an infinite loop or logic error occurred.
- [ ] **Natural Language Queries**: Ask "Where did variable 'i' change to 5?" and have the visualizer jump there.

### Phase 6: Object-Oriented & Advanced Java
- [ ] **Class instance visualization**: Render actual objects in the "Heap Space" with property tracking.
- [ ] **Method Call Stacks**: Support for multi-method programs with visual "push/pop" animations.
- [ ] **Array/List Visualizer**: Dedicated horizontal views for iterating through arrays and collections.
